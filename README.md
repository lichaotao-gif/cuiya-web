# 四川萃雅官网部署说明

本项目是无框架依赖的静态网站，页面数据中的媒体报道与政策文件由远程接口提供。

后续功能规划见 [`ROADMAP.md`](./ROADMAP.md)。网站已支持“跟随系统 / 浅色模式 / 深色模式”，默认跟随系统，用户选择会保存在当前浏览器。

## 本地预览

```bash
npm run dev
```

默认访问地址以终端输出为准。

## 构建与发布

```bash
npm run build
```

将生成的 `dist/` 目录作为网站根目录发布。项目大量使用 `/assets/...` 形式的根路径，因此不要部署到域名子目录。

建议发布配置：

- HTML 与 `sitemap.xml`：`Cache-Control: no-cache`
- 带版本参数的 CSS/JS 与图片：允许长期缓存，并在内容更新时同步修改资源版本
- 开启 HTTPS、Brotli/Gzip 和 HTTP/2 或 HTTP/3
- 将未知页面回退到 `404.html`，并确保返回 HTTP 404 状态码

## 上线前必须确认

1. 正式域名为 `https://cuiya.cn`；若域名变化，需要同步修改 canonical、Open Graph、`robots.txt` 与 `sitemap.xml`。
2. 媒体报道和政策接口 `https://admin.bingotalk.cn` 必须允许正式域名访问。
3. 现有 `/static/` 目录必须继续保留。以下内容仍引用旧站资源：
   - 融合出版页面的两段视频
   - 空中课堂页面的产品截图
   - 下载中心的二维码
4. 下载入口依赖 `bingobook.cn` 与 `bingoclass.com.cn`，发布后需逐项抽查。
5. 留言表单目前有意隐藏，后端服务接入前不要移除页面上的 `hidden` 标记。

## 发布后验收

- 检查首页、关于我们、研究院、四个公开产品详情页、媒体报道、政策文件和下载中心。
- 分别用桌面端与手机端检查导航、图片、视频、二维码和下载链接。
- 切换“跟随系统 / 浅色模式 / 深色模式”，确认跨页面保持且内容清晰。
- 打开一篇媒体报道与一篇政策文件，确认远程数据能够加载。
- 输入一个不存在的地址，确认展示品牌 404 页面且响应状态为 404。
- 检查浏览器控制台没有资源加载错误。
